# 技能进化管家（skill-evolution-steward）

已注册技能的修改与升版纪律管家：问题分流定去向，patch/minor 自主改并记谱系，major 过用户 Go/No-Go 门，写后五步验证。

## 结构

- `SKILL.md` — 技能入口
- `references/` — 参考文档

## 安装

- **通用 Agent Skill 平台（Claude / CodeBuddy / Cursor 等）**：将本目录放入平台的 skills 目录即可
- **TeleAgent / Octop**：导入本技能包后启用
